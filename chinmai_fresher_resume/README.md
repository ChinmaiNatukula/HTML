# Natukula Chinmai — Fresher Resume Website

A responsive HTML + CSS resume with a professional navy/blue palette, subtle reveal animations, project cards, social links, and print-to-PDF support.

## Files
- `index.html` — resume content and structure
- `style.css` — layout, colors, responsive design, animations, print styles
- `assets/profile-photo-placeholder.svg` — temporary profile photo illustration

## Run it
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. To edit the resume, open `index.html` in VS Code or another text editor.

## Add your own photo
1. Save a professional headshot inside the `assets` folder, for example as `chinmai-photo.jpg`.
2. In `index.html`, find:
   `<img src="assets/profile-photo-placeholder.svg" ...>`
3. Change the source to:
   `<img src="assets/chinmai-photo.jpg" alt="Natukula Chinmai" />`
4. Use a clear head-and-shoulders photo with good lighting and a simple background.

## Update your links and location
- The GitHub link is set to `https://github.com/ChinmaiNatukula`; verify that this is your intended profile URL.
- The LinkedIn link is a placeholder (`https://www.linkedin.com/`). Replace it with your full LinkedIn profile URL.
- The location currently says `Hyderabad, India`; change it if you want a different location shown.

## Save as PDF
1. Open `index.html` in Chrome or Edge.
2. Click **Download / Print PDF** near the top.
3. In the print dialog, select **Save as PDF**.
4. Turn on **Background graphics** for the navy header and color accents. Use A4 paper size.

## Important before sending applications
- Check all dates and project details and add internship dates if needed.
- Keep only technologies you can confidently explain in an interview.
- If you have a LinkedIn URL, replace the placeholder.
- The second project, **Student Savings Goal Tracker**, is a Java project description suitable for a resume if it accurately matches your implementation. Adjust it to match your actual code.
- This is a visual web resume; the project descriptions and text can be edited directly in `index.html`.
